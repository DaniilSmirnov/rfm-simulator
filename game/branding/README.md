# Фирменная иконка Rally Fans Map

`rfm-icon.svg` — неизменённая SVG-иконка из репозитория владельца проекта:
https://github.com/DaniilSmirnov/rfm-pwa/blob/f7ffe623836b7f3b9a78b3d7d5f435d6ddae95bd/icon.svg

Фирменный сайт: https://rallyfansmap.ru/
На 2026-10-06 прямое получение оригинальных файлов сайта из среды разработки возвращало
502 с сообщением об истёкшем сертификате. Поэтому использована локальная копия из Companion,
а не внешняя ссылка и не заново нарисованный знак. Полное совпадение с текущим favicon сайта
не проверено. Иконка используется как project icon и boot splash; Godot экспортирует из неё
favicon, apple-touch-icon и изображение экрана загрузки. Собственные условия использования
бренда не подменяются лицензией MIT игры.
