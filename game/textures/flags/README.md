# Kazakhstan flag

`kazakhstan.svg` is the unchanged 1000 × 500 vector from:
https://commons.wikimedia.org/wiki/File:Flag_of_Kazakhstan.svg
Direct source: https://upload.wikimedia.org/wikipedia/commons/d/d3/Flag_of_Kazakhstan.svg
Retrieved 2026-10-19. Flag designer: Shaken Niyazbekov.

The source identifies this state symbol as public domain (PD-KZ-exempt,
Article 8 of Kazakhstan's Law on Copyright and Neighboring Rights).

Reference for the 1:2 proportions, sun, steppe eagle and hoist ornament:
https://www.akorda.kz/en/state_symbols/kazakhstan_flag

Keep the complete artwork and aspect ratio. Both camp flags share one imported
texture on a two-sided vertical quad; the reverse is mirrored like real cloth.
