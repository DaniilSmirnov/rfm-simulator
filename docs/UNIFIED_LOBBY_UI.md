# Единый интерфейс выезда

Все пользовательские старты проходят через общий экран комнаты: создать выезд или войти по шестизначному ID. Отдельной кнопки «С друзьями» больше нет. Создатель может играть один и передать ID позднее.

Машина и СУ показываются в двух карточках с 3D-превью реального игрового мира. Превью рендерятся один раз при изменении выбора или размера окна, используют общий World3D и не продолжают рендериться на каждом кадре. Компоновка с двумя карточками предназначена для ПК и горизонтальных мобильных экранов; существующая подсказка поворота устройства сохранена.

Просмотр закрытого контента не даёт права начать игру. Создание комнаты требует доступа к выбранной машине и СУ. Вход по ID требует доступной личной машины; трассу гость временно получает от хозяина. Защита остаётся в PlatformService, start_game и серверном API. Клиентский selected_car / selected_stage до старта — выбор для превью, а не подтверждённое право владения.

В игре пауза хозяина останавливает общий мир и показывает гостям постоянное сообщение до продолжения. Собственная пауза гостя не останавливает мир. В меню паузы есть «Продолжить» и «В главное меню»: выход отправляет leave, закрывает комнату для хозяина и перезагружает сцену, даже если запрос завершился ошибкой/таймаутом.

Проверки: test_lobby_ui.gd, test_vk_access.gd, test_selection.gd, test_room.gd. lobby_preview.gd создаёт desktop-lobby, desktop-locked, mobile-lobby, mobile-pause и mobile-host-pause в .cache/ui-screens; CI сохраняет их в visual-previews.
