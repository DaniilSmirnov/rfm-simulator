# Симулятор раллийного овоща — демо 0.3.0

Играбельное 3D демо на **Godot 4.4.1 или новее**, GDScript, без плагинов и внешних ассетов. ПК, клавиатура и мышь. Проверено на Godot 4.4.1 под Linux с программным OpenGL.

## Запуск на macOS / Windows / Linux

1. Распакуйте весь архив.
2. В Godot нажмите **Import** и выберите `project.godot` в папке `game`.
3. Дождитесь импорта звуков и нажмите **F5** (Run Project). В главном меню выберите «Поехали».

Это исходный проект, а не готовое `.app` или `.exe`. Для отдельной native-сборки установите Export Templates своей версии Godot и выберите платформу в Project → Export. Проект использует Compatibility / OpenGL; C# не нужен.

## Web и Cloudflare Workers

В репозитории лежат исходники в `game/`, уменьшенный шаблон движка в `engine/` и воспроизводимая сборка. `npm run build` скачивает проверенный по SHA-256 Godot 4.4.1, экспортирует актуальные исходники, сжимает WASM и создаёт `dist/`. Движок повторно компилировать не нужно.

В форме **Connect to a repository** на Cloudflare задайте:

| Поле | Значение |
|---|---|
| Repository | `DaniilSmirnov/rfm-simulator` |
| Worker name | `rfm-simulator` |
| Production branch | `main` |
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |
| Preview command | `npx wrangler preview` |
| Root directory | `/` (корень репозитория) |

Нажмите **Connect**. Workers Builds устанавливает npm-зависимости, затем запускает сборку и деплой. Дальнейшие push в `main` обновляют production; для других веток можно включить preview builds. Конфигурация статических файлов — `wrangler.jsonc`, директория `dist/`. Все файлы меньше 25 МиБ; R2 не нужен.

Используется Node.js 22 или новее и Python 3. Для Linux x64 Godot скачивается автоматически. На macOS / Windows задайте `GODOT_BIN` абсолютным путём к установленному Godot 4.4.1.

```sh
npm ci
npm test
npm run build
npm run dev
# После авторизации Cloudflare, для ручного деплоя:
npm run deploy
```

GitHub Actions проверяет 41 сценарий игры, Web-экспорт и конфигурацию Wrangler. Сам production deploy выполняется подключённым Workers Builds. Секреты Cloudflare в репозиторий не записываются.

Документация: https://developers.cloudflare.com/workers/ci-cd/builds/configuration/

## Новое в 0.3.0

- Автоматическое определение Android, iPhone и iPad, включая Safari с настольным User-Agent. Нативная мобильная сборка использует тот же интерфейс; первое касание на сенсорном устройстве также включает его.
- В машине: руль слева, газ, тормоз и задний ход справа. Пешком: стик слева, обзор свайпом по свободной части экрана, кнопки лагеря, пива, заездов и троса справа.
- Пауза и карта сверху. Управление поддерживает несколько пальцев; пауза, потеря фокуса и смена ориентации сбрасывают удерживаемые действия.
- Адаптивный интерфейс для вертикального и горизонтального экрана. На компьютере остаётся клавиатура и мышь.
- Для ручной проверки в Godot: `godot --path game -- --mobile-controls`.

## Новое в 0.2.0

- Анимация выпивания по B у стола: рука поднимает банку, открывает её, наклоняет к лицу и опускает. Добавлены звуки открытия и глотка. Пиво засчитывается при глотке; пауза замораживает анимацию, завершение выезда убирает руку.
- Пять раллийных моделей по мотивам ВАЗ 2101, 2102 (универсал), 2103, 2105 и 2107. Отличаются силуэты, фары, решётки, багажник на крыше / спойлеры, ливреи, номера, полосы и наклейки вымышленных клубов. Первые пять экипажей показывают все пять вариантов.
- Лес отрисовывается четырьмя MultiMesh-пакетами. Движение и столкновения рассчитываются скриптами; используется Dummy physics.

## Один выезд

Вы приезжаете до открытия СУ на старой легковушке. Проезжаете по гравию к одной из четырёх полян, паркуетесь и выходите. Можно выбрать поляну случайно или устроиться в любом месте вне самой дороги. Сначала стол, затем стулья и мангал. Шашлык готовится 35 секунд; у стола можно выпить пива и съесть мясо. Откройте СУ и смотрите ралли.

Каждый экипаж получает случайное событие: обычный проезд — 55%, вылет — 25%, застревание — 20%. Вылет происходит около текущего места зрителя; машина движется к обочине, а столкновение с ней завершает выезд. Застрявшему экипажу можно помочь тросом от собственной легковушки. Цель демо: съесть шашлык, посмотреть шесть экипажей и выжить. Пиво и помощь дают дополнительные показатели в итогах.

Заезд занимает около 3–5 минут. Время, ралли и приготовление еды останавливаются на паузе.

## Управление

| Кнопка | Действие |
|---|---|
| WASD / стрелки | Газ, задний ход, руль в машине; ходьба на ногах |
| Мышь | Обзор на ногах |
| Space | Тормоз |
| E | Выйти из остановленной машины / сесть рядом с ней |
| Q | Выбрать случайную поляну, отмеченную оранжевым на миникарте |
| F | Поставить стол перед собой вне дороги |
| C | Поставить два стула у стола |
| G | Поставить мангал и начать готовить шашлык |
| B | Выпить пиво у стола (3 порции, с перерывами) |
| X | Съесть готовый шашлык у лагеря |
| R | Открыть СУ, запустить заезды |
| T, удерживать | Закрепить трос рядом с застрявшим экипажем и вытаскивать |
| Home | Вернуть легковушку на СУ, пока заезды не начались |
| Esc | Пауза / продолжить |
| F8 | Демонстрация застревания экипажа |
| F9 | Демонстрация вылета |

### Как вытащить экипаж

Подгоните свою легковушку не дальше 24 метров от застрявшей машины. Подойдите к экипажу ближе 5 метров и удерживайте T. Видимый жёлтый трос соединит машины. Удерживайте кнопку 6 секунд рядом с экипажем либо в собственной машине. Если дистанция между машинами превышает 26 метров, трос срывается. После помощи экипаж продолжает СУ.

## Уровень и стиль

Авторская трасса длиной примерно 840 метров по мотивам атмосферы **Dyfi / Wales Rally GB**: извилистый гравий, хвойный лес, подъёмы, лесные поляны и угловатые дальние хребты. Это компактная художественная интерпретация, не географическая копия маршрута.

Ориентир — простая low-poly графика, тёплый свет, приглушённая зелень и бытовой походный инвентарь. Все модели процедурные, из собственных примитивов. Звуки моторов, леса и углей синтезированы для демо. Ассеты Dear Passengers / My Summer Car и других игр не использованы.

Справка об атмосфере Dyfi: https://mag.toyota.co.uk/2019-wales-rally-gb-preview/

## Что реализовано и что упрощено

- Аркадная кинематика машины: руль, задний ход, тормоз, подъёмы, замедление на обочине и в лужах, тряска, повреждение от деревьев и быстрой езды по колее.
- Пеший режим с обзором мышью и простыми столкновениями со стволами.
- Свободная установка лагеря; стол не ставится на СУ.
- Готовка, дым, анимация выпивания пива от первого лица, звуки, миникарта, задания, пауза, смерть и итоги выезда.
- Движущиеся раллийные машины, случайные вылеты и застревания, визуальный трос и помощь экипажу.

Подвеска и шины не являются физической симуляцией. Трос работает как аркадная лебёдка по удержанию кнопки, без расчёта упругости. Раллийные машины едут по маршруту и при вылете переходят на заданную траекторию. Пока нет сохранений, мультиплеера, других биомов, сидения на стульях или полноценных персонажей экипажей.

## Код

- `game/scripts/game.gd` — игровой цикл, управление, лагерь, события, интерфейс, звук.
- `game/scripts/stage.gd` — маршрут, земля, лес и поляны. Геометрия создаётся при запуске.
- `game/scripts/props.gd` — процедурные машины, мебель, мангал и трос.
- `game/scripts/minimap.gd` — миникарта с лагерем, экипажами и игроком.
- `game/tests/test_demo.gd` — проверка логики игрового цикла.

В `stage.gd` можно изменить длину, ширину, профиль дороги и положения полян. В `game.gd` — скорость движения, вероятности событий и время приготовления.

## Проверки

```bash
godot --headless --editor --path game --import --quit
godot --headless --path game --script res://tests/test_demo.gd
godot --headless --path game --quit-after 240 -- --smoke-test
```

41 проверка прошла. Автоматически проверяются движение и тормоз, остановка перед выходом, границы дороги, правила лагеря, приготовление, пиво, открытие СУ, застревание, трос, столкновение и победа. Добавлены проверки фаз выпивания, повторного нажатия, счётчика, паузы, прерывания и пяти разных экипажей. Рендер сцены и меню также проверены в Godot с OpenGL.

Для повторяемого скриншота сцены: `godot --path game -- --capture`. Для меню: `godot --path game -- --capture-menu`. Эти режимы записывают PNG рядом с папкой проекта и завершаются; обычный запуск их не использует.
